## Tech stack (this site)

Built with **Flutter Web**, deployed on **Firebase Hosting**.

### Run locally

```bash
flutter pub get
flutter run -d chrome
```

### Build & deploy

```bash
flutter build web --release
firebase deploy --only hosting
```
